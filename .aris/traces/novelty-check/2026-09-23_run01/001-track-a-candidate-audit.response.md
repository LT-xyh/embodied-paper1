FINAL STRUCTURED NOVELTY REVIEW (2024–Sep 2026; no exact-result paper found; per limits, no ABANDON without a named paper containing the result).

Candidate A — surprise-triggered recurrent-memory reset for state-only BC-RNN
1) Claimed delta: train/fit a one-step state-transition predictor f(s_t,a_t), calibrate normalized innovation e_t=||s_{t+1}-f(s_t,a_t)||, and at deployment hard-reset BC-RNN hidden state before the next action when e_t exceeds a held-out threshold. The scientific claim is that a post-action physical outcome mismatch makes the pre-event recurrent history stale, so destructive invalidation improves correction.
2) Closest named priors and exact non-overlap:
• GMP, “Gated Memory Policy: In-Context Memorization and Adaptation,” arXiv:2604.18933 (2026), https://arxiv.org/abs/2604.18933 and https://gated-memory-policy.github.io/: learned observation-conditioned binary history read gate, cross-attention memory and noisy historical actions; gate labels come from when history lowers action-prediction error; evaluates RoboMimic and human cup perturbation. It does not predict next physical state or hard-reset recurrent state after transition surprise.
• AURA-Mem, “AURA: Action-Gated Memory for Robot Policies at Constant VRAM,” arXiv:2606.02775, https://arxiv.org/abs/2606.02775, https://arxiv.org/html/2606.02775: action-utility/action-error surprise gates writes to a bounded fast-weight memory; no state-transition residual and no destructive hidden-state reset.
• MILES, CoRL 2025, https://proceedings.mlr.press/v270/papagiannis25a.html: periodically resets an LSTM at a fixed interval (twice collected waypoint count); no event trigger, no transition model, and reports little sensitivity to reset frequency.
• MEMBOT, arXiv:2509.11225, https://arxiv.org/abs/2509.11225: persistent SSM/LSTM belief memory for intermittent observation dropout; no stale-history invalidation.
• Contractive Dynamical Imitation Policies, ICLR 2025, https://proceedings.iclr.cc/paper_files/paper/2025/hash/297f7c6c56af81239f7c47d21558b75a-Abstract-Conference.html: contractive architecture guarantees perturbation/OOS convergence; no event-triggered reset.
• ResTacVLA, IROS 2026, https://arxiv.org/abs/2607.03387 and https://arxiv.org/html/2607.03387: visual→tactile residual uncertainty gates tactile token injection, not BC-RNN memory.
3) Verdict: PROCEED WITH CAUTION. No named published paper contains the exact state-transition-innovation→hard-reset result, so ABANDON is disallowed. The delta is reviewer-verifiable but thin because AURA/GMP already make surprise/action-error gating of memory central and MILES already uses recurrent resets; a reviewer may call this a reset heuristic unless event-local causality is isolated.
4) What would make it carry: matched closed-loop ablation against no reset, fixed-period reset (MILES), GMP/AURA-like action-error gate, soft decay, and reset after observation-only surprise; report innovation timing, hidden-state contamination, and recovery return conditioned on the same perturbation. If gains do not concentrate immediately after transition mismatch, reject the mechanism (scientific kill, not a novelty ABANDON).

Candidate B — controller-censoring-aware bounded-action BC
1) Claimed delta: if logged demonstrations are post-controller-clipped at ±1, model interior labels with Gaussian pdf and boundary labels with one-sided tail (Tobit/censored) likelihood, then execute the same clipped command. Claim: infer latent intended magnitude beyond the limit, preventing Gaussian BC inward contraction near reach/contact limits.
2) Closest named priors and exact non-overlap:
• Truncated Gaussian Policy for Debiased Continuous Control, AAAI 2025, https://ojs.aaai.org/index.php/AAAI/article/view/33988: bounded/truncated Gaussian PPO policy sampling addresses boundary-action bias; it does not treat demonstration labels as censored observations or train BC with a Tobit likelihood.
• Neuro-Inspired Inverse Learning for Planning and Control, arXiv:2605.24152 (2026), https://arxiv.org/html/2605.24152: documents that unimodal Gaussian BC contracts action mass toward the interior, but solves via forward-model sequence optimization leaving data support; no censored-label likelihood.
• Understanding Behavior Cloning with Action Quantization, arXiv:2603.20538 (2026), https://arxiv.org/abs/2603.20538: theory of quantized action labels/error; no one-sided controller clipping/censoring.
• HYDRA: Hybrid Robot Actions for Imitation Learning, arXiv:2306.17237, https://arxiv.org/abs/2306.17237: mode/waypoint/action relabeling and action consistency; no censored regression.
3) Data-provenance gate: robosuite’s official DataCollectionWrapper calls env.step(action), then records info["actions"] = np.array(action) (https://github.com/ARISE-Initiative/robosuite/blob/master/robosuite/wrappers/data_collection_wrapper.py); this is caller input, while clipping may occur inside controller. Therefore existing robomimic labels cannot be assumed post-clip: first prove logger/controller ordering, label semantics, and nontrivial boundary mass. If labels are pre-clip or saturation mass is negligible, kill the hypothesis before P0.
4) Verdict: PROCEED WITH CAUTION. No exact named 2024–2026 robotics result found, so no ABANDON. Novelty is a robot-specific observation model, but the method can look like a one-loss swap; it carries only if provenance, synthetic known-censoring recovery, and closed-loop boundary-task gains are shown. Required discriminators: standard Gaussian BC vs Tobit/censored BC vs truncated Gaussian vs Beta, same backbone/seeds; report boundary-dimension calibration and reach/contact success, not only NLL. Strongest objection is “simple likelihood replacement plus unverified labels.”

Relative triage: A has the stronger direct-prior overlap risk; B has the stronger premise/data-risk and loss-swap risk. Both remain caution, neither ABANDON. If a P0 is selected, B should begin with a read-only logger/provenance + saturation audit; A should begin with event-local reset falsification against periodic/action-error gates.
