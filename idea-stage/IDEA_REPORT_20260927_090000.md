## Literature landscape

This section maps the relevant 2024–2026 literature and records the evidence limits of this offline discovery run.

### Reproducible VLA evaluation and memory

OpenVLA (CoRL 2025) provides an open VLA baseline and emphasizes reproducible fine-tuning/evaluation. VLA-REPLICA (2026) and open evaluation harnesses expose practical reproducibility gaps in termination, normalization, and benchmark execution. MemoryVLA (2025), LifelongVLA (2026), PHASER (2026), StateMem and PredVLA make persistent temporal memory a crowded method family. A new generic memory module or replay diagnostic would therefore be a direct or near-direct collision and would also inherit the repository's runtime risk.

### Partial observability and state ambiguity

MEMBOT (2025) learns a task-agnostic belief encoder for intermittent observation in Meta-World/robomimic. Nguyen et al. (CoRL 2025) use state/history mutual information to improve memory under partial observability. Resolving State Ambiguity in Robot Manipulation via Adaptive Working Memory Recoding (RA-L 2026) explicitly targets state ambiguity with adaptive working-memory recoding across seven real-world tasks. These papers cover the broad claim that recurrent memory should disambiguate aliased observations.

### Predictive/action-conditioned representations

JEPA Policy (2026) uses future representation and action prediction for robot policies. CIVIL (2025), CAGE (ICRA 2025), Zero-Shot Visual Generalization (2025), ReViWo (ICLR 2025), and causal-confusion work (2025) already use causal, view-invariant, or consequence-oriented visual features. A generic auxiliary future-prediction, contrastive, causal, or view-invariant loss is therefore rejected as a loss swap.

### Robustness and intervention-aware control

WHIRL (CoRL 2026) and related intervention-aware world-model work model intervention/risk. DisDP (RLC 2025) and robust-imitation papers target distributional or visual robustness. Generic uncertainty, conformal safety, action abstention, recovery, or shift evaluation is excluded by the brief and accumulated evidence.

## Ranked ideas

Three mechanism hypotheses were generated, then aggressively screened.

### A. Counterfactual action-swap hidden-state consistency for recurrent BC — unresolved, high novelty risk

**Failure mode.** A single image/state can be visually aliased while the correct action differs because the recent action history changed an unobserved object state. Standard BC-RNN can collapse these prefixes.

**Hypothesis.** Training a recurrent policy hidden state to predict *action-conditioned successor-feature divergence* for paired prefixes that differ only by a logged action swap will separate control-relevant aliases and improve closed-loop performance under observation dropout, beyond ordinary recurrence and next-observation prediction.

**Method delta.** Keep BC-RNN and add an auxiliary head over two prefixes. Construct only physically valid adjacent trajectory pairs; use the recorded action and successor feature as the intervention label. Contrastive separation is applied when successor consequences differ, and attraction when consequences agree. This is a robot-specific interventional objective, not a generic visual augmentation or sample filter.

**Closest priors and boundary.** PAM/state-ambiguity recoding already changes working memory to resolve ambiguous observations; MEMBOT already learns persistent belief under dropout; JEPA Policy already predicts future representations; CIVIL and causal-confusion papers already seek causal visual features. The non-overlap would have to be the *action-swap paired-prefix construction plus consequence-divergence supervision inside a recurrent imitation learner*, demonstrated against all four families. Because PAM and JEPA are very close, this remains unresolved rather than admitted.

**Pilot (SKIPPED — RUNTIME NOT QUALIFIED).** Environment: robomimic/robosuite state-only BC-RNN on Lift, Can, Square, with synthetic observation dropout and controlled action-swap pairs; a second path would be Meta-World reach/push tasks. Data: existing public demonstration files and a qualified robomimic stack; no data was downloaded this run. Compute: 1–3 CPU/GPU days after runtime qualification, three seeds, frozen baseline encoder. Positive: paired-objective improves mean success by ≥10 percentage points on dropout/alias split while changing nominal success by ≤2 points and beats next-state-prediction and PAM-style memory controls. Kill: no improvement on alias split, improvement only from extra parameters/normalization, or a direct matching paper is found.

### B. Consequence-gated recurrent memory updates — unresolved, likely near prior

**Failure mode.** Recurrent policies update memory on every frame, allowing long stretches of nuisance observations or intermittent occlusion to overwrite a useful belief.

**Hypothesis.** A learned action-conditioned controllability predictor can gate *when* memory is updated: preserve hidden state when the current observation has no predicted controllable consequence, and update when it does.

**Method delta.** Add a binary/continuous update gate trained from short-horizon successor-state change conditioned on action; compare to always-update BC-RNN, random count-matched gates, raw state-change gates, and soft decay. This changes recurrent filtering dynamics rather than adding a larger memory.

**Closest priors and boundary.** PAM, MEMBOT, StateMem, PredVLA, PHASER, and the prior transition-surprise-reset branch all cover adaptive or persistent memory. The gate is therefore probably a near prior; it is retained only as an unresolved falsification target, not as a recommended paper direction.

**Pilot (SKIPPED — RUNTIME NOT QUALIFIED).** Same robomimic/Meta-World plan as A with observation dropout and nuisance-camera perturbations. Positive: fewer false memory overwrites and ≥10-point success gain at fixed parameter count; kill: raw state-change or soft decay matches it, or direct prior collision.

### C. Counterfactual intervention consistency for frozen VLA hidden states — rejected

This would replay a prefix under perturbed actions and enforce hidden-state separation only when predicted task consequences differ. It is a direct composition of predictive representation, causal visual imitation, and intervention-aware evaluation. It also requires a VLA checkpoint and a runtime not qualified here. Reject as direct/near prior and execution-risk heavy.

## Novelty verification

The exact claim was decomposed into: (i) partial-observability/state aliasing; (ii) action-conditioned successor prediction; (iii) paired counterfactual action swap; (iv) recurrent imitation hidden-state training; (v) closed-loop dropout falsification. Recent work already covers (i), (ii), and adaptive memory separately. PAM and JEPA make the combination close, and CAPE (arXiv:2606.07304) directly learns action-conditioned future latent outcomes with contrastive same/different-outcome alignment. The candidate is therefore not a clean new learning paradigm; its only potentially distinct claim is the robot-control use of *same-latent-state executable action interventions* to supervise recurrent hidden-state disambiguation.

## External critical review

The strongest objection is that the proposal is “CAPE/JEPA-style auxiliary loss plus recurrent memory,” with no substantive mechanism beyond extra future supervision. A valid pilot must use a known-latent POMDP or simulator: clone the same latent state, execute alternate valid actions, observe both successors, and hold out episodes. It must compare ordinary next-state prediction, transition-surprise/reset, generic action-conditioned contrastive learning, and capacity-matched adaptive-memory baselines. Positive evidence would support control-relevant intervention supervision; a null result would indicate a generic predictive auxiliary; invalid or shuffled-swap gains would imply leakage and kill the idea. The independent review recommends **PROCEED WITH CAUTION TO PILOT**, only after runtime qualification and exact interventions.
